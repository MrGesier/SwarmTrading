Darwin previously ran deterministic research when no API key was available and only prepared engineering tasks. This change adds a free-only OpenRouter research adapter, persistent shared quota accounting, and an isolated code-correction demo with independent tests and a Factory evidence panel.

Based on `darwin-v0.11-factory-evolution` (PR #1), so this PR contains the V3 increment only.

- Research: schema-validated ATLAS/CURIE/EVOLVE/JUDGE critique/MNEMOSYNE, bounded parameter mutations, explicit provider failures, cached responses and a shared 20-attempt rolling daily ceiling.
- Engineering: separate worker, controlled display-helper defect, Codex CLI using existing ChatGPT login, constrained code output, detached candidate, immutable contract tests, backend regression and frontend build. Successful candidates require human review.
- UI: real holding duration, signal-window explanation, actual provider labels and explicit distinction between parameter evolution and code proposals.

Validation: 80 backend tests and npm ci/TypeScript/Vite build passed locally. Complete mock correction reached READY_FOR_REVIEW. A real OpenRouter connectivity call succeeded from the running application. A manually triggered research epoch completed with 36 eligible strategies and 3 offspring; ATLAS, CURIE, JUDGE critique and MNEMOSYNE had validated real responses, with explicit deterministic fallback for rejected proposals. Offspring performance is not yet established. Real Codex invocation remains blocked by Windows access restrictions in the assistant session; the native launcher is provided. No CI run is claimed for this branch until published.

Limitations: the code demo repairs a presentation helper, not strategy formulas; no autonomous integration or profitability claim. Synchronous research calls can delay the local application during an epoch. No delta/gamma-neutral portfolio, funding or live execution validation. Real trading remains disabled. See DARWIN_DEMO_V3.md for evidence and remaining work.

# SwarmTrade Darwin V0.10 — Change log

## Genome V2

- Added authoritative gene schema and hard bounds in `backend/darwin/genome.py`.
- Added exit threshold, max holding time, cooldown, stop loss, take profit and confirmation ticks while preserving threshold/gain.
- Generation-0 rows are upgraded compatibly; SQLite adds `genome_json` automatically.
- FORGE executes all V2 semantics deterministically and records exit reasons / average holding time.
- CURIE can choose one of eight genes per controlled experiment; EVOLVE only mutates the approved gene within hard bounds.

## Vibe Factory

- Event courier animations for hypothesis, mutation, Judge, memory, champion and Codex flows.
- Animated JUDGE stamps (`KEEP`, `KILL`, `SCALE`, `RETEST`).
- Champion crown burst.
- Timeline filtering and playback scrubber.
- Genome V2 gene catalogue and strategy-gene inspector.
- OpenBot bridge status in Factory.
- Added standalone `Open Vibe Preview.cmd` / `vibe-preview.html` (synthetic demo only, no trading).

## OpenBot

- Existing four advisory AG-UI coworkers retained: ATLAS, CURIE, EVOLVE, MNEMOSYNE.
- Added token-protected role-scoped read-only context endpoint: `/api/openbot/context/{agent_id}`.
- Context is redacted and has no exchange credentials or execution method.

## Reliability

- Raw recorder can be disabled with `DARWIN_RECORD_RAW=false`.
- Per-session raw recording is bounded by `DARWIN_RECORD_MAX_PARTS` (default 240).
- Backend version / launcher expectation bumped to `0.10.0`.

## Validation in this package

- 33 backend tests pass.
- Full backend compile succeeds.
- `/api/health` returns `0.10.0`.
- Factory state exposes 320 paper accounts and Genome V2.
- OpenBot context returns 200 with the correct token and 401 without it.
- TypeScript syntax for key TSX entrypoints transpiles successfully with the global TypeScript compiler.
- Full `npm ci` / Vite build could not be completed in the packaging container because npm dependency installation timed out; Codex should run it locally.

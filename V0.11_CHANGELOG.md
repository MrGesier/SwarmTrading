# SwarmTrade Darwin V0.11 — Evolution Observatory + Factory Crew

## Evolution telemetry

- Added persistent epoch-by-epoch evolution history derived from the existing SQLite evaluation ledger.
- Added `GET /api/darwin/evolution`.
- Added a transparent 0–100 Research Quality Index with its components exposed separately.
- Added `IMPROVING / FLAT / REGRESSING / EARLY / WAITING` trend state and evidence confidence.
- Added champion change count, generation ladder, family champion history and Genome V2 mutation-pressure telemetry.
- Embedded the evolution object in `/api/factory/state`.

## Factory crew

The eight roles are no longer visually identical trolls. Each role now has a character aligned with its function:

- ATLAS — 🦉 Atlas Owl / conductor
- CURIE — 🐸 Curie Frog / scientist
- EVOLVE — 🦎 Evolve Chameleon / genome smith
- FORGE — 🤖 Forge Bot / paper operator
- JUDGE — 🦁 Judge Lion / arbiter
- MNEMOSYNE — 🐙 Memory Octopus / archivist
- CERBERUS — 🐺 Cerberus Hound / guardian
- HERMES — 🐦 Hermes Bird / courier
- CODEX — 🦝 Codex Raccoon / engineer

The Factory gives them distinct silhouettes/animations while preserving the same authority boundaries.

## Evolution UI

- Added Evolution Observatory under the animated Factory.
- Shows quality, alpha, fee-stress, evidence, drawdown and max generation.
- Adds epoch sparklines and a per-epoch quality ribbon.
- Adds lineage ladder and champion-family history.
- Adds per-gene mutation bars and current gene medians.
- Keeps explicit copy that these are paper-research metrics, not a forecast of live profitability.

## Validation

- Backend test suite expanded with evolution-history coverage.
- Live execution remains disabled by default and untouched by the evolution layer.
